# Fonts

Currently the site loads Cormorant Garamond and Jost from Google Fonts via CDN.

If you ever want to self-host them (for faster load times or offline use), download the font files and place them here, then update the `<link>` in each HTML file to use `@font-face` rules pointing to `../assets/fonts/` (or `assets/fonts/` from index.html).
