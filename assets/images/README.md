# Images

Place your site images here.

## Files to add:
- `preview.jpg` — Open Graph / social share image (1200×630px)
- `elijah.jpg` — Your photo for the About page designer section
- Any portfolio work images

## Referencing from pages:
From inside `pages/about.html`, reference images as:
```html
<img src="../assets/images/elijah.jpg" alt="Elijah Lake"/>
```

From `index.html` at the root:
```html
<img src="assets/images/preview.jpg"/>
```
